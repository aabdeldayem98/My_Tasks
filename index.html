      Outlook & calendar

      1 · Your tasks in Outlook Calendar

      Subscribe once. Every task appears on its due date as an all-day event, and Outlook keeps it up to date by itself (it checks every few hours).

      Outlook.com Outlook (work) Outlook desktop

      If a button doesn’t open the right place: in Outlook Calendar choose Add calendar → Subscribe from web and paste the link.
      Keep this link private — anyone who has it can see your task titles.

      2 · North Star inside Outlook

      1. Download the add-in file
      2. Open aka.ms/olksideload (Outlook on the web) → My add-ins → Add a custom add-in → Add from file → choose the file.
      3. Open any email → Apps (or …) → North Star. Use From email to turn the email into a task.

      It also appears in the new Outlook for Windows and Outlook for Mac with the same account. Work accounts: if “Add a custom add-in” is missing, your IT admin has turned it off.
